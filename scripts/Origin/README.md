# Origin（原始脚本）

此目录用于存放待检查、验证、修复或优化的**原始脚本**。

## 管理约定

- 用户提供的原始脚本放在本目录中，作为后续工作的基准版本。
- 检查、验证和修改时，不直接覆盖本目录中的原始文件。
- 修改后的版本放在本目录的上一级 `scripts/` 目录中。
- 修改版应使用清晰的文件名；必要时通过版本号区分迭代。
- 对比原始版与修改版时，以本目录中的文件为原始依据。

例如：

```text
scripts/
├── Origin/
│   ├── README.md
│   └── example.user.js       # 原始版本
└── example.user.js           # 检查、修改后的版本
```
